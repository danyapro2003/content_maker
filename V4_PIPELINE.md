# Пересказ V4

Стабильный V3: коммит b3747f1. V4 выбирается отдельным пунктом режима в приложении. V3 сохраняет прежнее оформление и алгоритм.

## Обработка

1. Общий проверенный пайплайн V3: кэш ASR и карты, план, монтаж, проверки зрителя и верности.
2. Для каждой языковой версии готовые слова клипа разбиваются по границам монтажных блоков.
3. STAGE_V4_CAPTIONS получает только выбранные реплики этой версии и номера блоков. Возвращает до трёх пояснений по 2–7 слов (до 60 символов), каждое с точной цитатой evidence_quote из своего блока.
4. Код проверяет номера блоков, длину, цитаты и минимальную длительность блока. STAGE_V4_CAPTION_AUDIT отдельно проверяет смысл, язык и отсутствие спойлеров. Ошибка пояснений не затрагивает уже сохранённые видео, но эта языковая версия не рендерится; причина остаётся в логах. Если модель вернула пустой массив, видео содержит только пословные субтитры, об этом сообщается в логе.
5. ASS: одно слово за раз по ASR-таймингу, лёгкое увеличение 94→100%, белый текст с обводкой в нижней части кадра. Перекрытия и переходы через склейку обрезаются. Если исходный элемент содержит несколько слов, его длительность делится между ними равномерно.
6. Пояснения: тёплый жёлтый текст сверху, плавное появление/исчезновение, 3–5 секунд (не дольше блока). Не перекрывают область субтитров.
7. Рендер сохраняется в отдельную папку прогона. Запросы, ответы, проверенные пояснения и ASS доступны в логах и temp/runs.

## Проверка

Автотесты: подтверждённые пояснения проходят; выдуманная цитата отклоняется до аудита; отрицательный аудит запрещает надпись; слова не перекрываются и не пересекают склейки; ASS экранирует управляющие символы. Полный набор из трёх групп тестов проходит. Локально создан и просмотрен кадр 8-секундного примера оформления build/v4_preview/preview.mp4. Надпись в демонстрации задана вручную, API для примера не вызывался. Генерация пояснений на реальном API пока не проверялась.

## Запуск

Выбрать «Пересказ 4.0 (слова + пояснения сцен)». Для сохранённой карты использовать прежние модель/провайдер/лимит. Режим «Продолжить анализ» может использовать кэш ответов V3; «Пересобрать истории по готовой карте» создаёт новый монтаж. Дополнительно до двух запросов на языковую версию (генерация и аудит), в пределах общего бюджета запросов.
