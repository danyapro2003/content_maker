# Архитектура проекта Content Clipper (Qt6 / C++)

## Цель
Создать оконное приложение на Qt6 для автоматического создания виральных нарезок (клипов/хайлайтов) из видеофайлов (MKV, MP4)[cite: 1, 6].

## Пайплайн системы
1. **Анализ метаданных:** запуск `ffprobe` через `QProcess` для получения JSON со структурой глав (`-show_chapters`), форматом и дорожками (`-show_streams`)[cite: 1, 6].
2. **Извлечение субтитров:** 
   - Поиск индекса полных русских субтитров в JSON[cite: 6].
   - Извлечение дорожки через `ffmpeg -map 0:s:X` в формате SRT[cite: 1, 6].
   - Если субтитров нет — транскрибация через локальный `whisper.cpp` с флагами `--vad -mc 0`[cite: 1, 3].
3. **Мультиагентный отбор хайлайтов (LLM):**
   - **Аналитик:** читает субтитры и пишет краткий синопсис сюжета[cite: 2].
   - **Скаут:** сканирует текст отрезками по 10-15 минут и собирает кандидатов[cite: 2].
   - **Продюсер:** отбирает 3–7 лучших моментов длительностью от 40 сек до 2 минут и возвращает строгий JSON с таймкодами и причинами виральности[cite: 1, 2].
4. **Рендер:** нарезка отобранных отрезков через `ffmpeg`[cite: 1].

## Требования к коду
- Архитектурное разделение UI (`MainWindow`) и логики (`PipelineManager`)[cite: 6].
- Использование асинхронного `QProcess`, сигналов и слотов Qt[cite: 6].
- Использование MSVC-совместимого C++[cite: 3].
