# Content Clipper — Хайлайты и Пересказ V5

На вкладке «Пайплайн» выберите режим «Хайлайты» или «Пересказ». На вкладке «Настройки» доступны общие параметры, ограничения каждого режима и дополнительные настройки обработки. Фоновая музыка включается отдельно для пересказа.

## Полная версия проекта

Тег [legacy-full-v5](https://github.com/danyapro2003/content_maker/tree/legacy-full-v5) сохраняет все прежние режимы и настройки. Полный SHA — 554c3841e8ded168247c676b1e3fad28dbe7ccdc. Ветка полной версии — codex/v5-stable-edit, ветка этой версии — codex/highlights-v5.

Для просмотра файла из архива используйте команду `git show legacy-full-v5:mainwindow.cpp`. Для сравнения версий — `git diff legacy-full-v5..HEAD`.

Настройки этой версии хранятся рядом с EXE в settings-highlights-v5.json. При первом запуске приложение переносит значения из соседнего settings.json. Обе версии используют существующие локальные модели и кэш.
